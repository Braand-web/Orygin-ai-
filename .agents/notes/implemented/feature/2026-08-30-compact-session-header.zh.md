# Agent Note: 紧凑会话标题栏

Status: implemented

[English](2026-08-30-compact-session-header.md) | 中文

## Problem

活跃会话标题栏用两行显示会话标题、模式、视图标签和工具入口，在到达记录流和输入框前占用了过多的会话列空间。

## Decision

将会话标题、谱系控件、视图标签和工具入口保留在同一行。保留现有标签语义和按会话作用域的 slot 贡献，只把标签列表移入标题行并减少间距和垂直内边距。空白会话仍完全隐藏标题栏。

## Consequences

活跃会话仍提供相同控件，但占用更少的垂直空间。记录流和输入框获得更多可用空间，会话状态、标签选择和工具入口 slot 的所有权保持不变。

## Testing

会话骨架测试继续验证活跃标题栏、标签列表的可访问名称以及 Chat/Trajectory 控件。GUI 和组装 Web 检查覆盖更新后的客户端构建产物。
